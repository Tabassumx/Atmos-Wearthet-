## ✨ About Atmos Weather

Atmos Weather is a clean and responsive weather application that delivers real-time weather information with a modern UI experience.

The project focuses on minimal design, smooth animations, dynamic weather visuals, and easy accessibility across all devices.

Unlike traditional weather apps that feel overloaded or outdated, Atmos Weather is designed to feel lightweight, elegant, and visually immersive.

---

## 🚀 Features

### 🌍 Real-Time Weather Data
Get accurate live weather information instantly.

### 🌡️ Temperature Details
- Current temperature
- Feels-like temperature
- Min & max temperature

### 💨 Atmospheric Information
- Wind speed
- Humidity
- Pressure
- Visibility

### 🌅 Sun Information
- Sunrise timing
- Sunset timing

### 🌫️ AQI (Air Quality Index)
Integrated AQI system with readable labels:

| AQI Level | Status |
|------------|---------|
| 1 | Good |
| 2 | Fair |
| 3 | Moderate |
| 4 | Poor |
| 5 | Very Poor |

### 🎨 Dynamic UI
The interface changes based on weather conditions for a more immersive experience.

### 📱 Fully Responsive
Optimized for:
- Mobile devices
- Tablets
- Laptops
- Desktop screens

### ⚡ Fast & Lightweight
Built using pure frontend technologies without unnecessary frameworks.
