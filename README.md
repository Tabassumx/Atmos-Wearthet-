## ✨ About Atmos Weather

Atmos Weather is a modern animated weather web application designed to deliver real-time weather information with a clean, immersive, and responsive interface.

The project focuses on blending weather data with atmospheric visuals to create a more engaging user experience instead of traditional static weather layouts.

Atmos is built with simplicity, performance, smooth animations, and futuristic UI aesthetics in mind.

# 🌙 Realistic Moon Simulation

Atmos is planned to include a realistic moon rendering engine.

Features under development:
- Real-time moon phases
- Accurate moon illumination
- Dynamic moon glow
- 3D moon rendering
- Astronomically accurate transitions

Supported phases:
- New Moon
- Waxing Crescent
- First Quarter
- Waxing Gibbous
- Full Moon
- Waning Gibbous
- Last Quarter
- Waning Crescent

Example:
If the moon is between Waning Gibbous and Last Quarter,
Atmos will visually simulate the exact transition realistically.

Most weather apps use static moon icons.
Atmos aims to create a true atmospheric moon experience.
